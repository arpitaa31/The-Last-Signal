# The Last Signal

The Last Signal is a simple Three.js space website.

You can scroll through space and follow a strange signal.

The project has planets, stars, animations, and camera movement.

## Made With

- HTML
- CSS
- JavaScript
- Three.js

## How to Run

Open the project folder in VS Code.

Use Live Server, or run:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000

- I made this project to learn Three.js and understand how 3D websites work. Don't judge if it looks messy :), I was js learning!
